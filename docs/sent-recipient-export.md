# 按文章导出已发送收件邮箱

在 **文件 → 按文章导出已发送收件邮箱** 中导出 CSV，用 Excel 或其他表格软件打开。
Windows 的同名入口位于应用菜单中。

- 默认读取所有已添加账号，不受当前选中账号或文件夹的影响。
- 导出前显示每个账号本地已同步的已发送邮件数量，包括数量为零的账号。
- 每篇文章一行：文章名、全部去重收件邮箱、去重邮箱数、发件账号、发送邮件数、主题变体数、合并方式和主题示例。
- “主题示例”从该组已发送邮件中随机选取最多两个不同的完整主题，在同一单元格内换行显示；只有一个主题时显示一个，没有主题时留空。每次导出会重新抽取。
- 收件、抄送、密送邮箱一起去重，以分号分隔，保留没有可见收件地址的发送记录。
- 先识别《文章名》，再使用全部账号中的文章名匹配没有书名号的主题。分隔符、字数、笔名等投稿信息不再把同一篇文章拆开。明确的“投稿｜文章名｜字数”等格式也可以识别。
- 多个文章名、普通通信或无法可靠识别的主题保留原文，并在“合并方式”列标记，避免误合并。不会把不同标题仅凭相似字词合并。

例如“《质子府里养忠犬》-短篇-沐眠投稿-12171字”与“短篇 | 质子府里养忠犬 | 爽文 | 1.22万字”会合并为“质子府里养忠犬”一行。不同发件账号发出的同一文章也会合并。

软件导出范围是**本地已同步的已发送邮件**。尚未同步的历史邮件不在其中；应先完成账号同步再导出。它不会发信、修改已读状态，也不会导出授权码、正文或附件。CSV 使用 UTF-8 BOM，支持中文，并转义公式前缀。

实现使用邮件本身的已发送文件夹／标签筛选，不以整个会话代替已发送邮件，因此同一会话中的收到的回复不会被误计入。导出读取一次数据库快照；成功写入临时文件后再替换目标文件。
