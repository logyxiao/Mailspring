# 人工回复耗时统计

在 **文件 → 导出人工回复耗时** 导出 Excel 文件。Windows 的入口位于应用菜单。
工作簿包含“回复耗时汇总”“按回复邮箱统计”“人工回复明细”和“未配对回信”四张表。

## 筛选与配对

- 默认包含全部已配置账号的本地已同步邮件，不依赖当前选中账号。
- 配对后，仅保留其已配对回复涉及至少两个不同发件邮箱的回复邮箱。判定依据与“按回复邮箱统计”中的“发件账号”列一致；同一邮箱重复添加账号不会被算作两个发件邮箱。
- 仅关联一个发件邮箱的回复邮箱，其统计行、回复明细及未配对回信均不导出。所有平均值、中位数和样本数基于保留的数据重新计算；汇总另列排除数量。没有发回有效回复的其他发件账号不用于凑足两个账号。
- 按用户要求排除主题含“自动回复”、`AutoReply`、`AutoReplay`、`Re:` 的来信（英文忽略大小写），并纳入已配置的静默主题关键词。即使某封 `Re:` 来信确实由人工撰写，也会排除。中文“回复：”不单独排除。
- 这是一套按主题筛选的统计规则，不能证明未被排除的邮件一定由人工撰写。
- 优先使用回复引用头追溯到发件；否则要求同账号、同对方邮箱，完整主题或文章名匹配，且只有一封时间不晚于回信的候选发件。
- 多封候选发件、无法配对、缺少有效日期、回复早于发送等情况列入“未配对回信”，不猜测最近一封发件。
- 同账号中相同邮件标识的文件夹副本去重。自己发给自己的邮件不视为外部回复。
- 每封发件、每个回复邮箱只将首次符合筛选条件的回信计入平均值。后续回复保留在明细中，标记为不计入平均值。没有回复的发件不按零耗时计算。

## 周末计算

每个样本同时保留三项小时数：自然耗时、扣除周末耗时、按编辑设置计算的有效审核耗时。

- 默认扣除周六、周日，仅扣除实际重叠的时段。例如周五 18:00 至周一 10:00，自然耗时 64 小时，扣除周末后 16 小时。
- **偏好设置 → 常规 → 回复统计** 可保存周末审稿的编辑邮箱，每行一个。这里的邮箱是编辑回信的邮箱，不是自己的发件账号。
- “按回复邮箱统计”表中的黄色“周末审稿”单元格可以选择“是／否”。更改后，Excel 会重新计算明细和汇总的有效审核耗时；不会改变自然耗时，也不会写回软件设置。
- “曾在周末回复”仅表示导出的有效回信中出现过周末回信，不能自动证明每个周末都审稿，因此不自动修改规则。
- 使用电脑本地时区划分周末；不额外扣除夜间、法定节假日，也不处理调休工作日。耗时基于邮件时间戳，不是工作日 9:00–18:00 的工时。

## 正文与数据范围

尝试下载已配对回信的缺失正文，最长等待 45 秒，仍缺失时明确标记“正文尚未下载”。不会发送邮件、改变已读状态或加载邮件中的远程图片。

“人工回复内容”转换为纯文本并尽量去掉历史引用；“原始回复正文（含引用）”保留可读取的全部正文文本。超出 Excel 单元格字符上限时分到相邻续列，不丢弃尾部文本。附件内容不在此次正文导出范围内。

本地尚未同步的邮件不在统计范围内。发件和回信日期来自邮件时间戳；异常或缺失日期不会计入平均值。汇总、每个邮箱的平均值和黄色设置所影响的有效耗时具有 Excel 公式及导出时的计算结果。
